  1. 1. Tổng Quan Kết Quả Thực Thi
  2. 2. Chi Tiết Quy Tắc Mapping Field Trên 3 Object
  3. 3. Danh Sách 36 Bản Ghi Visit_Plan__c Đã Tạo Trên PROD

1. Tổng Quan Kết Quả Thực Thi

Bước Object Số lượng CSV Thành công Lỗi Ghi chú
Bước 1 Visit_Plan__c 36 36 0 Bao gồm 18 FLS, 9 AFS, 7 PDN, 2 MPR (Status__c = 'Planned')
Bước 2 Visit__c 101 101 0 Đã liên kết Visit_Plan__c, Vendor__c (Khách hàng), Dealer_Name__c (Đại lý)
Bước 3 Customer_Basic_Data__c 101 101 0 Đã liên kết Visit__c, Visit_Plan__c, Customer_Name__c, Account__c

2. Chi Tiết Quy Tắc Mapping Field Trên 3 Object

2.1. Object 1: Visit_Plan__c (File 1. Visit Plan.csv – 36 bản ghi)

Cột trong CSV Field API (Visit_Plan__c) Kiểu dữ liệu Quy tắc chuẩn hóa & Ghi chú
*Visit Plan Name Name Text(80) Giữ nguyên tên kế hoạch từ file CSV.
*Start Date Start_Date__c Date Chuyển đổi định dạng ngày (18-thg4-2026, 7/31/2026...) sang chuẩn ISO YYYY-MM-DD.
*End Date End_Date__c Date Chuyển sang chuẩn ISO YYYY-MM-DD (nếu trống thì lấy bằng Start_Date__c).
*Visit Plan ID External_ID__c Text(255) (External ID) Lưu mã kế hoạch (PDN_VSP_00001..00007, MPR_VSP_00001..00002, FLS_VSP_00001..00018, AFS_VSP_00001..00009).
Note Note__c Text(255) Ghi chú kế hoạch.
(Mặc định) Status__c Picklist Set nhãn hiển thị Planned (API Value: Duyệt Kế Hoạch).

2.2. Object 2: Visit__c (File 2.Visits.csv – 101 bản ghi)

Cột trong CSV Field API (Visit__c) Kiểu dữ liệu Quy tắc chuẩn hóa & Ghi chú
Visit Plan ID Visit_Plan__c Master-Detail(Visit_Plan__c) Lookup Salesforce ID của bản ghi Visit_Plan__c tương ứng vừa tạo ở Bước 1.
Dealer Name / Dealer Code Dealer_Name__c Lookup(Account) Map sang Salesforce ID của Đại lý trên PROD (để trống nếu là Only IVC).
Customer Name Vendor__c Lookup(Account) Map sang Salesforce ID của Khách hàng (Business Account) trên PROD (nhãn "Khách hàng").
Visit code Name Text(80) Lưu mã Visit code.
Visit Status Visit_Status__c Picklist Completed.
Visit by + Visit member Note__c Text(255) Gộp Visit by và Visit member để hiển thị trên công thức báo cáo Visit_nNote__c.
Planned Date Planned_Date__c Date Chuẩn hóa về YYYY-MM-DD; đồng thời gán Planned_Action__c = 'V'.
Check-In/Out Datetime Check_In_Datetime__c / Check_Out_Datetime__c DateTime Chuẩn hóa về ISO 8601 múi giờ Việt Nam (+07:00), bao gồm quy đổi các giá trị số serial Excel.
Check-In/Out Location Check_In_Location__c / Check_Out_Location__c Text(255) Lưu chuỗi tọa độ GPS Check-in / Check-out.
Visit Type Visit_Type__c Picklist CV.

2.3. Object 3: Customer_Basic_Data__c (File 3. Customer Basic Data.csv – 101 bản ghi)

Cột trong CSV Field API (Customer_Basic_Data__c) Kiểu dữ liệu Quy tắc chuẩn hóa & Ghi chú
Visit code Visit__c Lookup(Visit__c) Lookup 1-1 tới Salesforce ID của bản ghi Visit__c vừa tạo ở Bước 2.
Visit Plan ID Visit_Plan__c Lookup(Visit_Plan__c) Lookup tới Salesforce ID của bản ghi Visit_Plan__c vừa tạo ở Bước 1.
Customer Name Customer_Name__c & Name Lookup(Account) & Text(80) Customer_Name__c lưu ID Account Khách hàng; Name lưu tên khách hàng (tối đa 80 ký tự).
Dealer Account__c Lookup(Account) Lookup tới Salesforce ID của Account Đại lý.
Customer Rank Customer_Rank__c Picklist (Restricted) Chuẩn hóa về 4 giá trị hợp lệ trên PROD: FLS Diamond, FLS Platium, FLS Gold, FLS Silver.
Report Status Report_Status__c Picklist (Restricted) Chuẩn hóa từ Completed sang giá trị API hợp lệ Complete.
Check-In (Latitude / Longitude) Check_In__Latitude__s / Check_In__Longitude__s Location Tách cặp tọa độ số thực từ CSV; bỏ qua nếu là #N/A hoặc NA.
Các trường thông tin khảo sát Representative__c, Person_Interviewed__c, Head_Office_Address__c, Established__c, Total_Isuzu__c, Total_Hino__c, Total_Thaco__c, Total_HYD__c, Total_Other__c, Business__c, Office_Shops_Warehouses__c, Capital__c, Annual_Turnover__c, Strategy__c, Staff__c, Driver__c, Cargo_Owner_Partner__c, Operation_Route_Goods__c, Purchase_Plan_Inquiry__c, Maintainance_Repair__c, Customer_Comments__c, Other_Information__c, Customer_satisfaction_on_ISZ_dealer_netw__c, Customer_satisfaction_on_ISZ_product__c, Next_Action__c Text / Number / Date / LongTextArea Chuẩn hóa kiểu số (>40 → 40), kiểu ngày và giữ nguyên toàn bộ nội dung báo cáo.
